Brain Tumor MRI Classification using pretrained backbone:

This repository contains a deep learning project for brain tumor detection and classification using MRI images. The model leverages a pre-trained VGG16 convolutional neural network with custom layers for classifying MRI scans into different tumor types or no tumor.


🧠 Overview
Magnetic Resonance Imaging (MRI) is a crucial tool for diagnosing brain tumors. This project demonstrates how deep learning can automate tumor detection and classification using a VGG16-based convolutional neural network.

Key features:
Multi-class classification: meningioma, glioma, pituitary, and no tumor.

Image preprocessing and augmentation.

Training with a frozen VGG16 base and fine-tuned layers.

Evaluation using classification reports and confusion matrices.

Visual tumor detection with confidence scores.
