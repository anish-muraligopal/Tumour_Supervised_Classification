Brain Tumor MRI Classification using pretrained backbone:

This repository contains a deep learning project for brain tumor classification using MRI images. The model leverages a pre-trained VGG16 convolutional neural network with custom layers for classifying MRI scans into different tumor types or no tumor.


Overview:
Magnetic Resonance Imaging (MRI) is a crucial tool for diagnosing brain tumors. This project demonstrates how deep learning can automate tumor detection and classification using a VGG16-based convolutional neural network.


Key Features:
1) Multi-class classification: meningioma, glioma, pituitary, and no tumor.

2) Image preprocessing and augmentation.

3) Training with a frozen VGG16 base and fine-tuned layers.

4) Evaluation using classification reports and confusion matrices.

5) Visual tumor classification with confidence scores.
